# Personal Portfolio Website

## About the Project

This is my personal portfolio website created using HTML and CSS.

The website showcases my profile, interests, projects, and provides a contact form for visitors to get in touch with me.

## Pages

### 🏠 Portfolio
The portfolio page includes:

- My name
- Web Developer title
- About Me section
- My Interests
- My Projects
- Social media links
- Footer

### 📩 Contact
The contact page includes:

- Name input
- Email input
- Message box
- Submit button
- Home button to return to the portfolio

## Technologies Used

- HTML5
- CSS3
- Google Fonts

## Features

- Simple and clean portfolio design
- Separate Portfolio and Contact pages
- Custom CSS styling
- Google Young Serif font
- Contact form
- Navigation between pages
- Responsive layout
